# SDD 실습 프로젝트

Claude Desktop에 로그인하고 Code의 로컬 세션에서 이 폴더를 연다. `/edu-flow start`로 환경을 확인하고 `/edu-interview`로 앱 목적과 MVP를 정한다.

- `npm start`: 로컬 미리보기. 출력된 주소를 브라우저에서 연다.
- `npm test`: 실제 존재하는 테스트 실행. 초기 테스트는 환경 검사다.
- `npm run doctor`: Node.js·Git·필수 파일 점검.

주최 측은 Node.js 24·Claude Desktop·Git을 미리 설치한다. 수강생 GitHub 계정·MCP는 필수가 아니다. 앱 코드는 src/, 테스트는 tests/, 요구와 계획은 .edu/에 둔다. 완료한 기능은 로컬 Git으로 기록하며 별도 history.md는 만들지 않는다.

프로젝트를 가져갈 때는 코드·문서·검사·스킬과 숨김 .git을 포함한 폴더 전체를 ZIP으로 복사한다. 복사본을 풀어 문서와 Git 이력이 있는지 확인한다. Claude 로그인 정보와 개인 인증 파일은 넣지 않는다. 집에서 개발하려면 동일 도구를 준비하고 프로젝트 폴더를 연다.
