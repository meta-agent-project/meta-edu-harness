# 선택 가능한 수업 예제: HTML 편집기

인터뷰에서 HTML 편집기를 선택했을 때만 이 자료를 읽는다. 모든 프로젝트에 적용하는 기본 요구사항이 아니다.

목적: HTML 자료의 문구와 배치를 시각적으로 고쳐 HTML 파일로 가져간다.
대상: 비개발자 한 사람이 사용하는 로컬 브라우저 앱.
데이터: 외부 DB·외부 API 없이 시작하고 편집 상태는 메모리에서 관리한다.

최초 spec은 SPEC-001이며 다음 8개 기능을 한 묶음으로 만든다.
1. 기존 HTML 파일 열기.
2. 여러 슬라이드의 썸네일 선택·이동.
3. 기존 문구 편집.
4. 텍스트 요소 추가.
5. 선택한 글자의 크기와 색 변경.
6. 단일 요소 드래그 이동.
7. 선택 요소 삭제.
8. 수정 결과 HTML 내보내기.

실습용 샘플은 검증 자료이지 특정 파일만 지원하라는 제약이 아니다.
입력 문서의 슬라이드·텍스트 선택 규칙은 spec에 명시한다.
MVP 사용 후 전체 로드맵을 작성하고 취소·배경색 등의 다음 기능을 정한다.
사용자가 기본 과제 변경을 명시하면 변경된 목적을 확인하고 그 범위에 맞춘다.
