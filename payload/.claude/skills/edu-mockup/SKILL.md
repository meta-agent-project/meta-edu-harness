# 사진을 참고해 목업 선택

1. 현재 spec·기존 화면·design-choice.md를 확인한다. 사용자 제공 참고 자료가 우선이며 기존 선택은 다시 묻지 않는다.
2. HTML 편집기 첫 화면이면 assets/design-shots/의 A 상단 도구 모음형, B 간결한 작업실형, C 캔버스 중심형 사진에서 주 기준·보조 예시 2개를 선택한다. examples.json의 요청과 해당 PNG 사진을 한 쌍으로 읽는다. 이미지 보기 도구가 없으면 보지 않았다고 알리고 특징 설명 또는 사용자 선택을 받는다. 다른 앱에 이 편집기 디자인을 강요하지 않는다.
3. 선택한 사진 2개만 확인하고 배치·색·여백·도구 위치에서 차용/제외할 특징을 design-choice.md에 적는다. 사진 속 추가 기능을 요구사항으로 편입하지 않는다. HTML 편집기에 PPTX 입출력을 자동 추가하지 않는다.
4. 확정한 동일 기능 범위로 a.html·b.html 두 정적 목업을 만든다. MVP는 전체 화면, 후속 기능은 바뀌는 부분만 다룬다. 두 안은 배치·사용 동선에서 의미 있게 달라야 한다. 사진 3종, 생성 목업 2안, 후속 테마 4개를 구분한다.
5. 사용자가 선택하면 selected.html과 선택 이유를 남기고 spec에서 연결한다. 미선택 상태로 designed 처리하지 않는다. 확정된 선택을 반복 확인하지 않는다.
6. 화면이 바뀌지 않으면 기존 디자인을 유지하고 생략 이유를 적어 edu-plan으로 연결한다. 후보 아이디어는 backlog로 보낸다.
