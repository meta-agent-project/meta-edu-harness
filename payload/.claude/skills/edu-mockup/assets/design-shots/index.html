예시 요청

발표 자료 편집기에 익숙한 사람이 쉽게 쓰도록, 기능을 상단 도구 모음에 모으고 슬라이드 목록은 왼쪽, 편집 속성은 오른쪽에 배치해줘.

  • 상단에서 열기·텍스트 추가·내보내기 찾기
  • 왼쪽 썸네일 → 가운데 캔버스 → 오른쪽 속성

참고할 특징

  • 작은 상단 막대에 핵심 동작만 배치

예시 요청

참고할 특징

  • 아래쪽 가로 썸네일과 넓은 중앙 캔버스
  • 오른쪽의 작은 속성 패널
